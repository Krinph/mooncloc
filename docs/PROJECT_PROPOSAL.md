# mooncloc 项目申报书

## 一、项目名称

**mooncloc** — MoonBit 生态的代码统计与圈复杂度分析工具

## 二、项目简介

mooncloc 是一个用 MoonBit 实现的 cloc 风格代码统计工具，同时提供库 API 与命令行工具。
它递归扫描目录树，按语言统计代码行、注释行、空白行与混合行，并给出每个文件的
圈复杂度（cyclomatic complexity）、注释率与代码复杂度密度等健康指标，支持
表格 / JSON / CSV / Markdown 四种输出格式。

项目为**原创实现**：统计口径与功能灵感参考通用工具 `cloc`（GPL 工具，不共享代码），
语言识别规则表为公开的语法事实整理，不存在代码移植或许可证冲突（Apache-2.0 发布）。

## 三、项目方向与适用场景

- 方向：**开发者工具 / 工具库**（代码统计、工程质量分析）
- 场景：
  - MoonBit 生态项目规模与工作量统计（本赛事有效代码量证明）
  - 代码审查前的注释率 / 复杂度体检
  - CI 中作为质量门禁（复杂度超阈值告警）
  - 多语言混合项目的技术栈盘点

## 四、核心功能（已完成）

1. **行级统计引擎**：按语言剥离注释与字符串字面量（块注释、多行字符串、raw
   字符串、嵌套块注释、shebang），正确分类代码/注释/空白/混合行。
2. **45 种语言支持**：MoonBit 优先，覆盖 C/C++/Rust/Go/Python/JS/TS/Java 等主流语言。
3. **圈复杂度分析**：统计控制流关键字与逻辑运算符分支点数。
4. **gitignore 风格排除**：`*`、`?`、`**`、目录模式、锚定模式，内置噪音目录排除。
5. **健康指标**：注释率、每百行复杂度、最复杂文件排名。
6. **四种输出格式**：对齐表格、JSON（含 health 段）、CSV、Markdown。
7. **CLI + 库双层 API**：库 API 可嵌入其他 MoonBit 项目。
